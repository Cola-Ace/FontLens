# 字镜 · FontLens 0.2.0

新增自定义根文件夹显示名称，修复部分旧字体的名称乱码，并优化大型字体库的扫描、筛选、详情读取与预览缓存。

## 下载与运行

下载 `FontLens-v0.2.0-win-x64.exe`，双击即可运行，无需安装。支持 Windows 11 x64，浏览、预览和统计均可离线使用。

## 新增与修复

- 自定义根文件夹支持右键重命名，显示名称会在下次启动时恢复；根目录使用带房屋标记的实心图标和加粗名称，下方显示完整路径，便于区分子目录。
- 修复部分使用 GBK、Big5、韩文、日文及 Macintosh 旧编码的字体名称乱码，改善列表和详情中的名称显示。

## 性能优化

- 扫描复用字体索引缓存快照，批量写入索引并合并列表更新，减少大型字体库加载时的重复读取与界面更新排队。
- 搜索与自然排序复用预处理后的名称和排序键，减少重复计算。
- 切换字体时取消过期详情读取，先显示字体详情，再计算字符集覆盖，减少快速切换时的等待。
- 近期预览位图在缓存预算内保留并复用，减少往返滚动时的重复渲染；复用缓存读写中的压缩器，降低分配开销。

## 升级说明

直接运行新版即可继续使用已有设置。字体索引与覆盖缓存会按新版本重新生成，无需手动清理。

完整操作说明见 [使用指南](https://github.com/Cola-Ace/FontLens/blob/v0.2.0/docs/USER.md)。
