# 字镜 · FontLens 0.4.0

改进字体浏览、预览与对比操作，并减少加载大型字体库时的等待和内存占用。

## 下载与运行

下载 `FontLens-v0.4.0-win-x64.exe`，双击即可运行，无需安装。支持 Windows 11 x64，浏览、预览和统计均可离线使用。

## 改进与修复

- 可在侧栏顶部添加字体文件夹，并为来源文件夹设置显示名称。格式菜单可直接选择文件类型，搜索无结果时可一键清除筛选。
- 可单独编辑、保存和恢复各语言的预设文案，并更新了中文预设。字体缺少文案中的全部字形时，预览会给出提示。
- 对比字样按所选字号和卡片宽度换行，预览重新生成时保留已有字样的位置与尺寸。
- 详情顶部集中展示全名、Family Name 和字样，文件信息可展开查看。字符集覆盖列表按可见范围渲染，原生字体的原始表只读取当前页所需的字节。
- 并发读取已有字体索引，在后台统计目录字体数量，并减少筛选和预览缓存的内存开销。

## 升级说明

直接运行新版即可继续使用已有设置、字体索引和覆盖缓存。新版在读取旧索引时自动更新缓存格式。

完整操作说明见 [使用指南](https://github.com/Cola-Ace/FontLens/blob/v0.4.0/docs/USER.md)。
