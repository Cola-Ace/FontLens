# 字镜 · FontLens 0.1.0

首个正式版本：面向 Windows 11 x64 的离线字体浏览工具，支持字体预览、并排对比、信息查看和字符集覆盖统计。

## 下载与运行

下载 `FontLens-v0.1.0-win-x64.exe`，双击即可运行，无需安装。浏览、预览和统计均可离线使用。

## 主要功能

- 浏览系统及当前用户安装的字体，也可递归读取自定义文件夹；支持 TTF、OTF、TTC、OTC、WOFF 和 WOFF2，提供全名搜索、格式筛选与自然排序。
- 使用字体自身显示列表字样，按具体字体文件与集合面预览；支持自定义文案、多语言文学预设、字号和行距，以及 2–4 款字体并排对比。
- 调整可变字体轴或选择命名实例，列表、详情与对比预览同步更新。
- 查看字体属性、字符与字形度量、完整名称记录、表目录及分页原始表数据。
- 统计 GB2312、GBK、GB18030-2022、通用规范汉字表、Big5、HKSCS、日韩字表和 Unicode 17.0 区块的覆盖情况，也可导入 UTF-8 字表。
- 支持浅色、深色与跟随系统，保存来源目录、分栏宽度和预览文案，并在本地缓存字体索引与覆盖结果。

## 使用说明

- 同一浏览范围内全名相同的字体只显示首次扫描到的一份；字体预览中的缺字位置留空。
- 覆盖统计按 Unicode `cmap` 中映射到非零 glyph ID 的码位计算；组合序列的实际显示可通过预览查看。
- 字体文件只读，移除来源不会删除字体。设置与缓存保存在 `%LocalAppData%\FontLens\`。

完整操作说明见 [使用指南](https://github.com/Cola-Ace/FontLens/blob/v0.1.0/docs/USER.md)。
