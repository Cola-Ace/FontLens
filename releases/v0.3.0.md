# 字镜 · FontLens 0.3.0

改善窗口启动与主题切换的视觉体验，修复字体列表字样对齐、自定义根文件夹图标及切换字体时的字符集覆盖闪烁。

## 下载与运行

下载 `FontLens-v0.3.0-win-x64.exe`，双击即可运行，无需安装。支持 Windows 11 x64，浏览、预览和统计均可离线使用。

## 改进与修复

- 修复启动时的白色闪屏，窗口显示前应用已保存的主题并准备首帧内容，同时保留 Windows 原生窗口启动动画。
- 主题切换时，界面与字体预览颜色平滑过渡，过渡时长与标题栏一致；预览复用已有位图，减少主题切换时的重复渲染。
- 调整字体列表中 Family Name 字样的垂直位置，并按屏幕像素对齐绘制，改善字样对齐与清晰度。
- 修复自定义根文件夹图标中的房屋标记在部分主题及选中状态下不清晰的问题。
- 切换字体时，详情、预览和字符集覆盖统计准备完成后统一更新，减少覆盖统计区域的闪烁。

## 升级说明

直接运行新版即可继续使用已有设置、字体索引与覆盖缓存，无需手动清理。

完整操作说明见 [使用指南](https://github.com/Cola-Ace/FontLens/blob/v0.3.0/docs/USER.md)。
