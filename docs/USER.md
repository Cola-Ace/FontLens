# 字镜 · FontLens

看字样，查字体，知覆盖。

## 浏览字体

启动后在左侧选择“全部”或“系统字体”。系统字体通过 DirectWrite 枚举，包含当前用户安装的字体。点击“添加文件夹”选择目录，便可递归读取其中的字体。展开自定义目录并选择节点，可查看该目录及子目录中的字体面。点击“移除当前来源”只移除索引来源，不会删除字体文件。

侧栏“主题”按钮在跟随系统、浅色和深色之间切换，选择会在下次启动时恢复。

拖动分隔线可调整侧栏、字体列表和详情栏的宽度；字符集支持页和许可证页也可调整左右区域比例。退出后再次启动会恢复上次调整的宽度，包括字体列表的列宽。

中间列表每行代表一个字体面；当前目录和格式范围内，全名相同的字体只显示首次扫描到的一份，比较时忽略大小写和首尾空白。不同字重或样式的全名不同，分别显示。侧栏数量也按各来源和目录内的全名去重。右列使用该面的实际字体显示 Family Name，文字固定，不受自定义文案和预设选择影响。工具条可调整字号。字体缺少 Family Name 中的字符时，列表会显示缺字码位。列表默认按名称升序展示；点击 Name 表头在名称升序、名称降序和原始顺序之间切换，每次切换都会回到列表顶部。搜索框按字体全名筛选，格式按钮可筛选文件类型。搜索和格式筛选不会改变左侧目录数量。

勾选 2–4 款字体后点击“对比”，可在独立视图中并排查看同一文案。自定义文案可以编辑多行，也可选择简繁中文、日、韩、英、法、德、西、葡、俄、阿拉伯及印地文节选；出处见 [预览文案出处](PREVIEW_TEXTS.md)。对比视图中的文案、预设、字号和行距与浏览页共用，点击“返回浏览”可保留原来的筛选与选择。

## 查看字体信息

选择列表中的字体面后，程序读取该面的详情，右侧显示全名、文件路径、集合面索引、Family Name、Subfamily、PostScript 名、字形数、Unicode 映射码位数、名称记录和表目录。切换字体时释放上一份详情。表目录列出长度、偏移和字体记录的 checksum；点击表可分页查看原始十六进制数据。TTF、OTF、TTC、OTC、WOFF 与 WOFF2 文件均按字体面读取，Web 字体在内存中解包，偏移指向解包后的数据。

“字符与字形查询”可输入单个字符、`U+4E00` 形式的码位或 `gid:12` 形式的字形 ID，查看选定字体面的映射与水平 advance、左侧 bearing；字符查询还显示该字体面的原生预览，并可复制字符或码位。

可变字体会显示命名实例和各轴范围。点击实例或拖动轴滑块、输入数值，列表字样、字符查询预览与对比视图会按当前轴值更新；“恢复默认轴值”返回字体声明的默认坐标。

字符集覆盖显示 GB2312 汉字集与 GBK 汉字集的已覆盖数、总数、百分比和缺字数。GB2312 分母为 6,763 字，GBK 分母为 20,923 字。GB18030 分级、通用规范、Big5/HKSCS 及日韩字表在缺少明确版本数据时显示“待导入”，不会显示虚假的 0% 覆盖。统计只计算所选 Unicode `cmap` 中映射到非零 glyph ID 的码位。

右栏的覆盖列表完整展开，可切换到 Unicode 17.0 区块并搜索统计项。“字符集支持”提供字表与区块并排视图。区块分母只含已分配字符，私用区单列。

点击“导入字表”可选择 UTF-8 文本字表，或带 YAML Front Matter 的逐行字符文件。程序按码位去重；若文件的 `count` 声明与实际数量不符，导入处会显示错误。导入数据保存在本地设置中，随后所选字体的覆盖统计会重新计算。

## 本地数据

字体文件只被读取。来源、当前目录、目录展开状态和导入字表保存在 `%LocalAppData%\FontLens\settings.json`，字体索引与覆盖缓存保存在同目录的 `index.db`。浏览和统计无需网络连接。
